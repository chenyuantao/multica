# iMind 笔记规则

笔记保存在共享根的 `iMind/` 目录，每条笔记一个 Markdown 文件。完整格式、生成模板、命名与媒体规则见 [笔记生成指南](../server/internal/imind/agent-instructions.md)。后端在初始化或读取笔记目录时，将此指南同步为 `iMind/README.md` 和 `iMind/AGENTS.md`；已有用户自写文件不会被覆盖。

## 作者

- YAML 顶层字段 `author` 为字符串，笔记列表直接显示非空作者。
- 新建普通笔记和语音笔记使用当前操作用户的名称，由后端填入。Agent 直接生成文件时也应使用该用户名称，无法获取时先确认。
- 剪藏使用原文章的署名作者，由剪藏 agent 从来源文章提取；无法确认时填写 `author: ""`，不得用剪藏用户、agent 或网站名称替代。
- 编辑已有笔记保留作者；旧笔记缺少该字段仍可读取，不按当前用户推断历史作者。

修改笔记规则时同步更新指南源码与示例测试。发布新版后端后，托管 README.md 和 AGENTS.md 会随目录初始化或读取刷新。
